# Телеграм-бот для чеков Яндекс / Индрайвер

Бот принимает PDF-чек из Kaspi, сам достаёт сумму, дату, время и службу,
спрашивает № заказа и кладёт строку в Supabase. Инструмент сводит эти строки
с отчётом 0080.

## 1. Создать бота

В Telegram напишите **@BotFather** → `/newbot` → имя и логин бота.
Он выдаст токен вида `8123456789:AA...` — держите его при себе, это ключ от бота.

Там же узнайте свой chat id: напишите **@userinfobot**, он ответит числом.

## 2. Таблицы в Supabase

SQL Editor → выполните `supabase_schema.sql` (если ещё не выполняли),
затем `supabase_receipts.sql`. Появится таблица `receipts` и приватное
хранилище `receipts` для самих чеков.

## 3. Развернуть функцию

На компьютере, где установлен [Supabase CLI](https://supabase.com/docs/guides/cli):

```
supabase login
supabase link --project-ref rgzymmcspoaoimqndbhb
supabase functions deploy telegram --no-verify-jwt
supabase secrets set TELEGRAM_TOKEN=токен_от_BotFather
supabase secrets set TELEGRAM_SECRET=любая_длинная_строка
supabase secrets set ALLOWED_CHAT_ID=ваш_chat_id
```

`TELEGRAM_SECRET` — придуманная вами строка, например 30 случайных символов.
Она защищает функцию от чужих запросов: Telegram присылает её в заголовке,
всё остальное функция отвергает.

`ALLOWED_CHAT_ID` — чей чат бот слушает. Можно перечислить через запятую,
если позже подключите операторов.

## 4. Подключить вебхук

Один раз откройте в браузере (подставьте свои значения):

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook
  ?url=https://rgzymmcspoaoimqndbhb.supabase.co/functions/v1/telegram
  &secret_token=<TELEGRAM_SECRET>
```

Должно ответить `{"ok":true}`. Проверить состояние: `/getWebhookInfo`.

## 5. Как пользоваться

1. В Kaspi откройте чек → «Поделиться» → отправьте **PDF** боту.
2. Бот отвечает: `Индрайвер · 01.09 14:17 · 2 551 ₸` и просит № заказа.
3. Отправьте номер из iiko (или `-`, если его нет).
4. В инструменте: Аналитика → карточка «🚕 Яндекс и Индрайвер» → «Обновить».

Команды: `/start` — подсказка, `/last` — последние 5 записей.

## Почему важен № заказа

У чека нет ни телефона, ни адреса — только служба, день, время и сумма.
На 1 сентября было два Яндекса с разницей в 5 минут: по времени их не
различить, и инструмент честно откажется угадывать. Номер заказа занимает
секунду, зато связка становится точной.

Без номера остаются два запасных пути:
сумма чека совпала с «Доставка сводная цена» в заказе — точно;
служба, день и ближайшее время — догадка, помечается «проверьте».
